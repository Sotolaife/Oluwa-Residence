# **App Name**: Oluwadara Residences

## Core Features:

- Property Listings: Display real estate properties with details like images, price, location, features, and virtual tour embed.
- Property Search and Filtering: Enable users to search and filter properties based on location, price range, beds, baths, property type, and featured status.
- Interactive Map Integration: Integrate Google Maps for location-based property search. Pin clicks navigate to property details.
- Contact Forms with WhatsApp Integration: Implement contact forms to record submissions in Firestore and send users a WhatsApp quick-link and enable phone call intent.
- Blog Management with react-markdown: Create a blog with markdown support, SEO meta, and accessible typography for real estate related articles.
- Agent Authentication and Admin Area: Implement Firebase Authentication for agents to manage property listings, testimonials and blog posts.
- Image Compression Optimization: Tool to Optimize image loading using lazy loading, responsive image sets and formats, and compression.

## Style Guidelines:

- Primary color: Emerald Green (#0F6B43) to evoke luxury and sophistication.
- Background color: Dark charcoal (#1A202C) provides a high-end, modern backdrop.
- Accent color: Warm metallic gold (#CDAA57) highlights interactive elements and important information, adding a touch of opulence.
- Headline font: 'Playfair', a modern serif, will be used for headlines to convey elegance. Body text: 'PT Sans', a humanist sans-serif, will be used to make the text highly readable. 
- Generous white space, rounded cards, soft shadows, and subtle glass panels for overlays to enhance the luxurious feel.
- Use Framer Motion for micro-interactions like card hovers and smooth page transitions.
- Use minimalist and elegant icons to represent various property features and amenities.
